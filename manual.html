초과콕 사용설명서

퇴근 후·출근 전·휴일에 매시 정각 "초과근무 기록하세요"라고 알려 주는 앱입니다.

1설치하기

  1. 설치 파일 overpoke_0.1.0_x64-setup.exe를 더블클릭합니다.
  2. 파란 경고창이 뜨면 추가 정보를 누르고, 이어서 나오는 실행을 누릅니다.
  3. 사용 안내를 읽고 동의함 → 설치를 누릅니다.

Windows의 PC 보호

Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.
추가 정보① 누르기
② 누르기실행실행 안 함

개인이 만든 무료 앱이라 디지털 서명이 없어서 뜨는 경고입니다. 믿을 수 있는 사람에게 받은 파일만 실행하세요.

2근무시간 정하기

처음 실행하면 설정 창이 자동으로 열립니다. 근무시간 메뉴에서 출퇴근 시각을 맞추고 저장을 누릅니다.

저장

이렇게 두면 알림은 이때 옵니다.

  • 평일: 18:10, 19:00, 20:00 … 다음 날 08:00 (근무시간 중에는 안 옴)
  • 주말·공휴일: 하루 종일 매시 정각

평일 아침은 출근 1시간 전(8시)보다 먼저 PC를 켰을 때만 알립니다. 8시 이후에 켜면 정시 출근으로 보고 알리지 않습니다. 주말·공휴일은 언제 켜든 바로 알립니다.

공휴일은 자동으로 받아옵니다. 회사 창립기념일처럼 목록에 없는 쉬는 날은 수동 공휴일에 날짜를 추가하세요.

3알림이 오면

화면에 이런 창이 뜹니다. 초과근무를 기록하고 확인을 누르면 닫힙니다.

19:00
초과근무 기록 버튼을 누르세요
오늘은 그만확인
  • 확인: 창을 닫습니다. 다음 정각에 또 알립니다.
  • 오늘은 그만: 오늘은 더 알리지 않습니다. 실수 방지를 위해 두 번 눌러야 하고, 자정이 지나면 다시 켜집니다.

4작업 표시줄 아이콘

설정 창을 닫아도 앱은 꺼지지 않고 화면 오른쪽 아래 작업 표시줄에 머뭅니다. 아이콘을 왼쪽 클릭하면 설정 창, 오른쪽 클릭하면 메뉴가 열립니다.

설정
오늘 알림 끄기
종료
^가오후 7:00

아이콘이 안 보이면 작업 표시줄의 ^(숨겨진 아이콘)를 눌러 보세요.

5휴대폰으로도 받기 (선택)

자리를 비웠을 때도 알림을 받고 싶으면 켜세요. 아래는 텔레그램으로 받는 방법입니다. 나만 쓰는 알림용 봇을 하나 만듭니다.

  1. 텔레그램에서 @BotFather를 검색해 대화를 열고 /newbot을 보냅니다.
  2. 봇 이름(예: 초과콕)과 아이디(끝이 bot, 예: chogwa_kim_bot)를 차례로 보내면 토큰을 줍니다.
    예: 7712345678:AAHk3x… — 비밀번호와 같으니 남에게 보여 주지 마세요.
  3. 방금 만든 봇과 대화를 열어 시작을 누르고 아무 말이나 한 번 보냅니다.
  4. PC 브라우저 주소창에 https://api.telegram.org/bot토큰/getUpdates를 넣어 엽니다.
    화면에서 "chat":{"id":123456789의 숫자가 chat_id입니다.
  5. 설정 창 휴대폰 알림에서 텔레그램을 체크하고 봇 토큰과 chat_id를 넣습니다.
  6. 텔레그램 테스트를 눌러 휴대폰에 메시지가 오면 저장.

6자주 묻는 것

PC를 켤 때 자동으로 실행되게 하려면?
설정 창 일반 → 컴퓨터를 켜면 자동 실행을 체크하고 저장합니다.
알림이 안 와요.
PC가 꺼져 있거나 절전 중이면 알림이 오지 않습니다. 설정 창 오늘 메뉴에서 "오늘은 알림을 껐습니다"라고 나오면 다시 켜기를 누르세요.
팝업 위치를 바꾸고 싶어요.
설정 창 일반 → 팝업 위치에서 화면 가운데 / 오른쪽 아래 중 고르세요.
앱을 끄거나 지우려면?
끄기: 작업 표시줄 아이콘 오른쪽 클릭 → 종료.
지우기: Windows 설정 → 앱에서 overpoke를 찾아 제거.
초과콕은 기록을 잊지 않게 도와주는 알림 도구일 뿐입니다. 초과근무 기록과 신청은 본인이 직접 확인해 주세요.
