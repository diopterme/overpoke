# 초과콕

**퇴근하고 나서 초과근무 기록 버튼 누르는 걸 자꾸 잊어버리나요?**

초과콕은 근무시간이 아닐 때 **매시 정각마다 "초과근무 기록하세요"라고 알려 주는** 작은 알림 앱입니다.
PC 화면에 알림 창을 띄우고, 원하면 휴대폰으로도 알려 줍니다.

## 언제 알려 주나요?

| 날짜 | 알림 시간 |
| --- | --- |
| 평일 | 출근 전, 퇴근 후 매시 정각 (근무시간 중에는 조용함) |
| 주말·공휴일 | 하루 종일 매시 정각 |

예를 들어 근무시간이 9시~18시라면 평일에는 **18:10, 19:00, 20:00 … 다음 날 08:00**에 알림이 옵니다.

- 평일 아침은 출근 1시간 전(8시)보다 먼저 PC를 켰을 때만 알립니다. 8시 이후에 켜면 정시 출근으로 보고 알리지 않습니다. 주말·공휴일은 언제 켜든 바로 알립니다.
- 공휴일은 앱이 알아서 받아옵니다. 회사 창립기념일처럼 따로 쉬는 날은 직접 추가할 수 있습니다.
- 오늘 더는 알림을 받기 싫으면 "**오늘은 그만**"을 누르세요. 자정이 지나면 다시 켜집니다.

## 다운로드

- **Windows**: [overpoke_0.1.0_x64-setup.exe](https://github.com/diopterme/overpoke/releases/latest/download/overpoke_0.1.0_x64-setup.exe)
- **Mac** (M1 이후): [overpoke_0.1.0_aarch64.dmg](https://github.com/diopterme/overpoke/releases/latest/download/overpoke_0.1.0_aarch64.dmg)
  — 열어서 앱을 응용 프로그램 폴더로 끌어 넣습니다.
"확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다.

## 사용 방법

1. **설치** — 설치 파일을 실행합니다. 파란 경고창이 뜨면 **추가 정보 → 실행**을 누릅니다.
2. **근무시간 맞추기** — 처음 실행하면 설정 창이 열립니다. 출근·퇴근 시각을 맞추고 **저장**을 누릅니다.
3. **끝** — 이제 창을 닫아도 됩니다. 앱은 화면 오른쪽 아래 작업 표시줄에 숨어서 계속 동작합니다.

알림이 오면 초과근무를 기록하고 **확인**을 누르면 됩니다.

> 그림과 함께 보는 자세한 설명은 [사용설명서](https://diopterme.github.io/overpoke/manual.html)를 열어 보세요.
> 휴대폰 알림(텔레그램) 연결 방법, 자주 묻는 질문도 거기 있습니다.

## 알아 두세요

- 초과콕은 **알려 주기만** 합니다. 기록과 신청은 직접 해야 합니다.
- PC가 꺼져 있거나 절전 중이면 알림이 오지 않습니다.
- 회사 PC에 설치하기 전에 회사의 프로그램 설치 규정을 확인하세요.
- 개인이 만든 무료 앱이라 설치할 때 경고창이 뜹니다. 믿을 수 있는 사람에게 받은 파일만 실행하세요.
