# 초과콕

초과콕은 근무시간이 아닐 때 매시 정각마다 "초과근무 기록 버튼을 누르세요"라는 알림 창을 PC 화면에 띄우는 앱입니다.
퇴근 후 초과근무 기록 버튼을 잊지 않게 하려고 만들었습니다. 원하면 휴대폰으로도 같은 알림을 보냅니다.

## 언제 알려 주나요?

| 날짜 | 알림 시간 |
| --- | --- |
| 평일 | 출근 전, 퇴근 후 매시 정각 (근무시간 중에는 알리지 않음) |
| 주말·공휴일 | 하루 종일 매시 정각 |

근무시간이 9시~18시면 평일에는 18:10, 19:00, 20:00 … 다음 날 08:00에 알림이 옵니다. 퇴근 후 첫 알림 시각(18:10)은 설정에서 바꿀 수 있습니다.

- 평일 아침에는 출근 1시간 전(8시)보다 먼저 PC를 켰을 때만 알립니다. 8시 이후에 켜면 정시 출근으로 보고 알리지 않습니다. 주말과 공휴일에는 PC를 켠 시각과 상관없이 바로 알립니다.
- 앱이 공휴일 목록을 인터넷에서 받아 옵니다. 창립기념일처럼 회사만 쉬는 날은 설정의 "회사 쉬는 날"에 직접 넣으세요.
- 오늘 더는 알림을 받지 않으려면 알림 창에서 "오늘은 그만"을 두 번 누르세요. 자정이 지나면 알림이 다시 켜집니다.

## 다운로드

- Windows: [overpoke_0.1.1_x64-setup.exe](https://github.com/diopterme/overpoke/releases/latest/download/overpoke_0.1.1_x64-setup.exe)
- Mac (M1 이후): [overpoke_0.1.1_aarch64.dmg](https://github.com/diopterme/overpoke/releases/latest/download/overpoke_0.1.1_aarch64.dmg)

Mac에서는 dmg 파일을 열고 앱을 응용 프로그램 폴더로 끌어 넣습니다. "확인되지 않은 개발자" 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다.

## 사용 방법

1. 설치 파일을 실행합니다. Windows에서 파란 경고창이 뜨면 "추가 정보"를 누르고 "실행"을 누릅니다.
2. 처음 실행하면 설정 창이 열립니다. 근무 시작과 종료 시각을 맞추고 "저장"을 누릅니다.
3. 설정 창을 닫습니다. 앱은 작업 표시줄 오른쪽 아래 트레이에 남아 계속 알림을 보냅니다.

알림이 오면 초과근무를 기록하고 "확인"을 누르세요.

그림이 있는 자세한 설명은 [사용설명서](https://diopterme.github.io/overpoke/manual.html)에 있습니다. 휴대폰 알림(텔레그램) 연결 방법과 자주 묻는 질문도 사용설명서에서 볼 수 있습니다.

## 알아 두세요

- 초과콕은 알림만 보냅니다. 초과근무 기록과 신청은 직접 해야 합니다.
- PC가 꺼져 있거나 절전 중이면 알림이 오지 않습니다.
- 회사 PC에 설치하기 전에 회사의 프로그램 설치 규정을 확인하세요.
- 개인이 만든 무료 앱이고 코드 서명을 하지 않아서 설치할 때 경고창이 뜹니다. 믿을 수 있는 사람에게 받은 파일만 실행하세요.
